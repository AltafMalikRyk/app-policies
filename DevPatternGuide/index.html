DevPattern Guide (com.articode.app.devpatternguide)

1. Zero Data Collection

DevPattern Guide collects zero personal data, code snippets copied, search terms, crash reports, or device identifiers. All technical study happens privately on your device.

2. Zero Permissions

DevPattern Guide requests zero dangerous or runtime Android permissions:

All SOLID principles, GoF design patterns, code samples, syntax highlights, and reading themes are packaged offline inside the application binary. Saved bookmarks and typography settings reside purely in local SharedPreferences and delete on uninstall.

DevPattern Guide is created for general engineering and student audiences (13+ / 18+), gathers zero personal details from any user, and adheres fully to COPPA and Play Store privacy standards.
