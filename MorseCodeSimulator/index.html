ℹ️ 1. Introduction & Overview

Welcome to the Privacy Policy for Morse Code Simulator. This application is an interactive audio-visual and historical telegraph simulation created purely for education, Morse code literacy, and tactile telegraph key appreciation.

We respect your privacy completely. Morse Code Simulator operates 100% locally on your device with no network communication, no background tracking, and zero personal data collection.

🛡️ 2. Information We Collect

Zero Personal Data Collection: We do not collect, request, process, harvest, store, or transmit any personal data whatsoever. Specifically, we do not access:

  • User identity, real name, email, phone number, or postal address.
  • Device serial numbers, IMEI, Android Advertising IDs (AAID), or hardware parameters.
  • Geographic locations, GPS coordinates, or approximate network geolocation.
  • Camera imagery, microphone recordings, photo galleries, or local storage documents.
  • Transmission records, translated texts, contacts, or browsing history.

⚙️ 3. How We Use Information

Because zero user data is ever accessed, collected, or stored, no personal information is used, evaluated, commercialized, or shared. All user preferences—such as plinth material, tone frequency, volume, and typed ticker tape—exist solely in local runtime memory during your active session.

📱 4. Device Permissions

Morse Code Simulator requests no sensitive or dangerous Android runtime permissions. The only permission requested is:

  • android.permission.VIBRATE: Used solely to generate tactile vibration pulses when the brass key lever makes mechanical contact. This permission cannot read private user files or connect to network services.

🚫 5. Third-Party Services & SDKs

Morse Code Simulator does NOT include any third-party analytics libraries, advertising frameworks, telemetry tools, or tracking SDKs. There is zero integration with platforms such as AdMob, Unity Ads, Firebase Analytics, or data brokers.

👶 6. Children's Privacy (COPPA Compliance)

Morse Code Simulator is safe, educational, and suitable for users of all age groups, including students and children under 13. We strictly adhere to the Children's Online Privacy Protection Act (COPPA), GDPR-K regulations, and Google Play's Families Policy. We do not solicit or gather data from minors.

🔒 7. Data Security & Storage

Because the app contains no remote cloud servers or data transmission sockets, your mobile device remains fully isolated and secure while using the simulation.

We may occasionally revise this Privacy Policy to ensure alignment with platform enhancements or statutory guidelines. Any updates will be reflected directly on this webpage.
